# CRITS Jiji catalogue import files

The technology import contains 125 new product records prepared as drafts. The current shop categories are Computers & Laptops (ID 1), Printers, Copiers & Scanners (ID 2), and Printer Supplies & Accessories (ID 3). 11 products already in the shop were left out, and repeated advert paths were deduplicated.

Import the technology CSV through Admin → Import / export. Imports remain drafts for staff review. Confirm every price, description, photo and stock level before publishing. No Jiji advert/source URLs are included. Product photos are image URLs hosted by Jiji.

The property CSV contains two land listings with public descriptions and photo galleries. Import it from Admin → Real estate → Import property CSV. Imports create drafts, skip records whose slug is already present, and never publish automatically. Review the price, availability, description and photos before publishing.

The non-IT review CSV separates the Nissan and printer repair service. Create the suggested Other Listings and IT Services categories from Admin → Categories → Add missing categories. These two review rows are not included in the technology product import; add and approve each listing through the Products form after confirming its details.

The descriptions, asking prices, conditions and photos came from public seller listings. Prices and availability may change; verify them with CRITS staff before publishing.
